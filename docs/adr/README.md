# Architecture Decision Records

An ADR records an important architectural decision and the tradeoffs behind it.
Create one when a decision changes contracts, persistence, provider boundaries,
security posture, deployment model or long-term operating behavior.

## Template

```md
# ADR: Short Decision Name

## Context

What situation forced a decision?

## Options

- Option A
- Option B
- Option C

## Decision

What option was selected and why?

## Consequences

What improves, what becomes harder and what must be watched?
```

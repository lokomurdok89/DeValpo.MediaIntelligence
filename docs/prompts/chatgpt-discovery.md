# ChatGPT Discovery Prompt

Use this when discussing a new idea with ChatGPT or another consulting AI.

```text
We are working on DeValpo.MediaIntelligence.

Goal:
[Describe the idea or problem.]

Context limits:
- Do not assume source code changes yet.
- Keep the output actionable and concise.
- Ask clarifying questions only if they block a useful spec.

Output format:
1. Functional spec
2. Technical spec
3. Scope
4. Out of scope
5. Risks
6. Acceptance criteria
7. Suggested implementation sequence
```
